# 动态路径演化实验（DTE-RR）

第二篇论文修订版与学位论文第 4 章扩展部分的实验代码。对应脚本：`8_dynamic_path_evolution.py`。

## 一、这组实验要回答什么

第 4 章原有的方法是"静态路径 + 执行期局部修补"：路径在开始时确定，之后只做重试、补救、恢复三类局部动作。本组实验检验把这条链路升级为"**学习者状态双时间尺度演化 + 路径滚动重规划**"之后，学习结果与过程指标如何变化。

四类策略（同一批学生、同一随机流，配对比较）：

| 策略 | 含义 |
|---|---|
| `static` | 按初始状态规划一次，之后不再改动；执行期只做局部修补（原方法） |
| `evolve` | 同上，但加入能力慢增长、情绪向基线回归、性格对参数效力的调制 |
| `roll` | 在 `evolve` 之上，按状态滚动重规划路径（本方法） |
| `roll_nostab` | 同上，关闭稳定性正则（消融，用于分离"重规划"与"防抖动"的贡献） |

## 二、模型要点

**四维画像**：性格（尽责性 C、神经质 N、开放性 O，慢变量）、能力 a（累积变量）、情绪 e（快变量）、条件（交互预算、时间压力，外生）。

**双时间尺度演化**

- 快尺度（每轮）：`e ← e + ρ(ē − e) + δ_f·1[fail] − δ_r·1[rest] − δ_p·1[pass]`，基线 `ē = 0.12 + 0.40N + 0.15τ`，回归速率 `ρ = 0.08 + 0.12(1−N)`。
- 慢尺度（每 5 轮）：`a ← a + η(1−a)·max(0, s̄ − 0.5)`，`η = 0.03 + 0.05C`，`s̄` 为窗口成功率。
- 性格调制：视频恢复效力 `0.60 + 0.25O + 0.10(1−N)`；补救效力加成 `0.04C`。

**滚动重规划**：目标代价 = 预计失败风险 + 理想难度失配 + 绕行成本 + 重复访问惩罚；理想难度 `d* = 0.30 + 0.45a − 0.25e`。触发条件为开局、每 8 轮复核、当前目标连续失败 2 次、情绪跨越 0.70 阈值。常规重规划锁定当前目标、只重排后续；卡住时才允许把当前目标后移。稳定性正则对"首目标被替换"施加惩罚。

**先修准备度**：`p_succ` 含 `0.35 × prep` 项，`prep` 为目标直接前驱中已掌握的比例。这一项是"顺序为何重要"的因果前提——没有它，任何排序都等价。

**路径压缩**：当 `risk(t) ≤ 0.45` 时允许直接挑战目标、跳过桥梁概念，对应"能力提升后可跨步迁移"。

## 三、运行

```bash
python 8_dynamic_path_evolution.py --quick  # 小样本自检，约 2 秒
```

## 四、主要结果（种子 20261108，18 个任务 × 4 类学生 × 30 人）

| 策略 | 完成/% | 掌握/% | 峰值情绪 | 轮次 | 退出/% | 失配/% | 路径变更 | 变更幅度 |
|---|---|---|---|---|---|---|---|---|
| static | 55.74 | 81.04 | 0.659 | 36.7 | 7.18 | 73.7 | 0 | 0 |
| evolve | 54.54 | 79.54 | 0.656 | 35.4 | 11.62 | 72.6 | 0 | 0 |
| roll | **57.82** | 81.01 | **0.650** | **33.9** | 10.65 | **71.5** | 3.1 | 0.44 |
| roll_nostab | 56.99 | 80.55 | 0.650 | 34.3 | 11.16 | 71.2 | 3.0 | 0.44 |

配对差值（10,000 次自助）：`roll − static = +2.08`，95% 区间 `[−0.05, 4.31]`，**区间下界贴近 0**；`roll − evolve = +3.29`，区间 `[1.16, 5.42]`，不含 0；`roll − roll_nostab = +0.83`，区间含 0。

**必须如实说明的三点**：

1. 相对静态基线的完成率提升只是边缘显著，不能宣称"大幅提高"。真正稳定的增量来自"演化 + 重规划"合起来相对"只演化"的 3.3 个百分点。
2. 静态策略的退出率反而最低（7.18%）。原因是它不改变计划、情绪扰动少；动态策略以 2 个百分点的退出上升换取了更短的路径与更高的完成率。这是权衡，不是纯优势。
3. 轮次减少 2.8 轮（7.6%）不能被换算为学习时间的节省，它只说明达到同样目标所需的交互步数更少。

**条件依赖**（`d5_budget`、`d6_shock`）：

- 预算 30 / 40 / 50 / 70 时，动态增益为 `+0.78 / +4.69 / +7.81 / −0.78` 个百分点。约束适中时收益最大，预算充裕时收益消失——这与"重规划的价值来自资源稀缺下的取舍"一致。
- 能力跃迁（第 18 轮 +0.15）时增益 `+5.47`；情绪冲击（第 18 轮 +0.35）时增益 `0`。前者可控、后者突发，说明方法对"可解释的状态变化"有效，对"一次性冲击"帮助有限。

**异质性**（`d2_heterogeneity`）：9 个性格组合中 5 正 4 负，范围 −10.1 至 +6.3。低尽责低神经质（+6.25）与中等尽责高神经质（+5.29）受益最大；低尽责高神经质（−10.10）受损最重——这类学生情绪波动大，重规划频繁改道反而打断先修积累。这一结果支持稳定性正则的必要性，也说明"动态"并非对所有学生都更好。

**观测条件**（`d4_lag_prior`）：情绪观测滞后 0 / 1 / 2 / 3 轮时完成率为 65.62 / 63.28 / 75.00 / 59.38，非单调，波动落在抽样噪声范围内，不能解读为"滞后有益"。自评能力偏差 −0.10 / 0 / +0.10 时，动态策略为 29.69 / 69.53 / 96.88，静态为 29.69 / 66.41 / 95.31；低估能力时两者同样受损，说明重规划无法弥补初始画像的系统性偏差。

## 五、与既有实验的关系

- 图谱、结构难度、情感失败系数、缺口惩罚、退出阈值与 `7_dual_state_extended_experiments.py` 一致，新增部分只做加法。
- 本组实验的"任务"是"起点 + 6 个待掌握目标"，不要求目标之间构成链；这与第 3 章"生成一条路径"不同，是为了让"先学哪个、走哪条路"成为可优化的自由度。
- 新增的 `prep` 项改变了 `p_succ` 的形式，因此本组数值不能与第 4 章表 4-3、表 4-4 直接比较，只能在本组内部比较。论文中已注明这一口径差异。
