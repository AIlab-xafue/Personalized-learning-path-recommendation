# 中期补充实验说明（脚本 11、12）

本目录原有 1–10 号脚本，2026 年 11 月为中期考核补充两组实验，用于回答学位论文第五章提出的两个问题：
**动态增益是否稳健**、**增益是否依赖初始路径形态**。两组实验均只读已有图谱与既有执行器，不改动原实验输出。

---

## 一、脚本 12：六种子稳健性（`12_multiseed_robustness.py`）

### 为什么做

8 号脚本报告过“roll 相对 static 完成率 +1.11 个百分点，95% 区间 [−1.02, 3.24]”，区间跨零。
单一种子的差值可能来自抽样波动，必须换种子重复才能判断方向是否稳定。

### 怎么做

固定执行器、学习者生成规则与任务规模（18 任务 × 4 类原型 × 20 名学习者），只改变抽样种子，
在 6 个种子上重复主比较，逐个体配对，5000 次自助给出区间。

### 结果（实际运行输出，见 `thesis_outputs/multiseed_robustness.json`）

| 种子 | 静态/% | 仅演化/% | 重规划/% | Δ(重规划−静态) | 95% 区间 | Δ(重规划−仅演化) |
|---|---|---|---|---|---|---|
| 20261108 | 56.32 | 54.24 | 57.99 | +1.67 | [−0.90, 4.38] | +3.75 |
| 20261109 | 61.67 | 61.88 | 62.43 | +0.76 | [−1.81, 3.40] | +0.56 |
| 20261110 | 52.78 | 49.72 | 54.72 | +1.94 | [−0.56, 4.44] | +5.00 |
| 20261111 | 54.58 | 53.54 | 55.76 | +1.18 | [−1.39, 3.68] | +2.22 |
| 20261112 | 60.76 | 60.21 | 61.25 | +0.49 | [−2.01, 2.99] | +1.04 |
| 20261113 | 54.65 | 55.42 | 59.58 | +4.93 | [2.43, 7.43] | +4.17 |

- Δ(重规划−静态)：均值 **+1.83**，范围 +0.49 ~ +4.93，**6/6 为正**，但多数单种子区间跨零。
- Δ(重规划−仅演化)：均值 **+2.79**，范围 +0.56 ~ +5.00，**6/6 为正**，两个种子区间不含零。

**结论口径**：稳定增益只能限定在“重规划相对仅演化”这一比较上；“重规划相对静态”应表述为“方向一致、幅度不稳定”。

## 二、脚本 11：路径来源敏感性（`11_path_source_sensitivity.py`）

### 为什么做

第 4、5 章的初始路径都是“起点 + 若干目标”的目标集形态，目标之间不要求相邻。
如果换成结构上已经连贯的链，动态重规划还有没有用？这决定结论能推广到哪类任务。

### 怎么做

三种来源、同一批学生、同一随机流、逐个体配对，路径长度统一为 7：

| 来源 | 构造方式 | 相邻边命中率 |
|---|---|---|
| S1 目标集 | `sample_problem`，目标间不要求相邻 | 3.70% |
| S2 合法链 | 沿真实边做无重复随机游走 | 100% |
| S3 最短链 | 起点到远端目标的 BFS 最短路径 | 100% |

### 结果（见 `thesis_outputs/path_source_sensitivity.json`）

| 来源 | 静态/% | 重规划/% | 差值/pp |
|---|---|---|---|
| 目标集 | 59.31 | 58.47 | −0.83 |
| 合法链 | 86.25 | 85.00 | −1.25 |
| 最短链 | 86.25 | 85.58 | −0.67 |

链式路径的静态完成率高达 86%，因为每个目标恰好是前一节点的后继，先修准备度接近 1，
重规划没有改进空间。目标集一列的 −0.83 与 12 号脚本的 +1.83 均值并存，
说明单次抽样差值波动可达约 2 个百分点，二者不构成方向性矛盾。

**结论口径**：动态重规划的作用条件是“路径与状态存在失配”；初始路径已结构良好时收益趋近于零。

## 三、运行方式

```bash
cd 3_dual_state            # 在仓库根目录执行
set PYTHONHASHSEED=0
python 11_path_source_sensitivity.py     # 约 1 分钟
python 12_multiseed_robustness.py        # 约 3 分钟
```

输出写入 `3_dual_state/thesis_outputs/`：

- `path_source_sensitivity.json|csv`
- `multiseed_robustness.json`

两组实验都通过 `importlib` 直接载入 8 号脚本的 `KG`、`Learner`、`Replanner`、`run_episode`，
不复制实现，因此执行器口径与第 4、5 章完全一致。若 8 号脚本被修改，这两组结果需要重跑。

## 四、需要如实保留的三点

1. 11 号脚本的目标集一列（−0.83）与 12 号脚本的均值（+1.83）符号不同，这是抽样波动，不是两组实验互相否定。
2. 六个种子与任务的组合里，只有少数区间不含零；论文不能把“均值提升”写成“显著提升”。
3. 12 号脚本的“仅演化”组在多数种子上低于静态组，说明状态演化本身不是收益来源，收益来自演化之后的计划调整。
