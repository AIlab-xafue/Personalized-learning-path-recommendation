# 个性化学习路径推荐演示平台

面向学生与答辩现场的可视化系统：**知识图谱约束 → 个性化路径 → 双态画像 → 动态重构**，
把学位论文第 3 章（软硬约束协同）与第 4 章（双态驱动、滚动重规划）的方法与结果，做成可以
现场操作、逐轮回放的界面。

## 一、运行

```bash
cd platform                # 在仓库根目录执行
python server.py            # 自动打开 http://127.0.0.1:8770
```

也可以双击 `启动平台.bat`。只依赖 Python 标准库，不需要安装 Flask；图表库 ECharts 已放在
`assets/` 下，**完全离线可用**。

> 直接双击 `index.html` 会白屏：页面用 `fetch` 读取 `data/*.json`，浏览器不允许 `file://`
> 跨源请求，必须通过上面的本地服务访问。

## 四、两套数值不要混用

- **双轨回放**：`assets/engine.js` 是 `8_dynamic_path_evolution.py` 的 JavaScript 复刻，
  公式与参数逐项对齐（见文件头注释），但随机流实现不同（LCG vs Python `random`），
  因此单次回放的步数不会与论文表格逐位一致。它用于**演示机制**，不用于报告结论。
- **群体面板**（实验证据页）：直接读取 Python 实验输出，与论文表格一致。

## 五、演示建议（约 3 分钟）

1. 「学习者画像」保持默认的**稳健均衡型**，目标 6 个，点"生成初始路径"。
2. 切到「静态 ⇄ 动态」，点"开始回放"：左轨始终按入学计划推进，右轨在情绪越过 0.70 时切视频、
   在认知失败后插先修补救、在连续卡住或情绪跨越阈值时重排剩余目标（路径上橙色标签即改道后的新节点）。
3. 回放结束看底部结论行：默认这一次抽样中，静态在第 50 轮耗尽预算仍未完成全部目标，动态在第 47 轮完成；
   但动态的峰值情绪与路径变更次数都更高——这是「以过程波动换完成率」的权衡，不要把单次回放读成「动态全面更优」。
4. 切到「实验证据」看总体：18 个任务上完成率 +1.11 个百分点（95% 区间跨 0，属边缘显著），
   增益主要来自"演化 + 重规划"相对"只演化"的 +2.27 个百分点；并把**异质性热力图**作为边界条件讲：
   高神经质学生的增益可能为负，这正是需要稳定性正则与教师介入的地方。

## 七、修订记录（2026-11，中期答辩前）

1. **修正恢复动作的日志口径**。此前界面把恢复后的负荷值直接写进“越过阈值”的提示，出现“情绪 0.21 越过阈值 0.70”这类自相矛盾的记录。现改为记录**触发时刻的观测负荷**
   （`engine.js` 中 `stepLog` 新增 `emotion` 记录触发值、`emotionAfter` 记录恢复后值、`reason` 记录触发原因），并按原因分两种文案：
   - `THRESHOLD`：观测负荷 X 超过阈值 0.70 → 切换视频资源恢复；
   - `AFTER_FAIL`：上一轮为情感性失败 → 再次切换视频资源恢复。
2. **演示口径不变**：单次回放仍只用于解释机制，不用于报告结论；群体面板仍直接读取 Python 实验输出。
3. 答辩演示建议按“学习者画像 → 生成初始路径 → 双轨回放 → 实验证据”的顺序，约 3 分钟。

## 八、第二轮修订（2026-11，针对"调参数路径不变 / 能力曲线看不出增长"）

### 8.1 规划器为什么之前不动

原实现的排序打分是**固定权重**的加权和，且六项里只有"能力 a"和"情绪 e"两个量随画像变化，
尽责性 C、神经质 N、开放性 O 只影响执行期，不进目标函数；再加上演示任务的 6 个目标结构
难度都在 0.83~0.84、与起点同样相距一跳，任何权重都无法把它们拉开。于是拖动滑块时，
只有能力被推到极端才会看到路径变化——这就是"路径不变"的真实原因。

### 8.2 改成了什么

1. **目标函数归一化后按画像加权**（`Replanner.rank`）。五项指标先在本步候选内缩放到同一量纲，
   再按权重合成，权重和为 1：

   | 指标 | 含义 | 由谁抬高 |
   |---|---|---|
   | 风险回避 risk | 该节点的预期失败率 | 神经质 N↑、时间压力 τ↑ |
   | 难度匹配 diff | 与理想难度 d\* 的距离 | 开放性 O↓（舒适区窄） |
   | 先修完备 gap | 未掌握前驱的比例 | 尽责性 C↑ |
   | 绕行成本 detour | 插入桥梁节点的代价 | 时间压力 τ↑ |
   | 长期价值 value | 掌握后解锁的下游概念数 | 尽责性 C↑、τ↓ |

   界面「初始路径」卡片直接列出这五个份额，学生能看到"为什么先排这个"。

2. **跳步阈值随性格变化**（`hopThresholdFor`）：神经质高 → 不敢跳过中间节点，会补齐更长的
   支架链；开放性高 → 允许直接跳到较远的目标。这解释了为什么不同性格的路径长度会差一倍
   （6 个节点 vs 13 个节点）。

3. **逐位贪心重排**：每一步都以"当前所在节点"为参照重新打分，前一步学了什么会改变下一步选谁；
   同时修掉了旧版会重复排入同一节点（如路径里连续出现两次「IP地址」）的缺陷。

4. **滑块实时重规划**（110 ms 节流）：不用再点按钮；卡片下方给出"第几位起改变、补上/省去哪些
   支架节点、长度从 X 到 Y"的差异说明；若确实没变，也会明说原因，而不是让人以为坏了。

5. **能力曲线**：纵轴改为按实际变化范围自适应放大，并在图下直接写出
   入学 a、静态与动态的终值与百分点差。

6. **新增「慢变量的累积效应」图**：同一学习者连续完成 5 次同类任务（能力跨任务保留），
   静态恒为一条水平线，双态逐次抬升。**这是展示性扩展，论文实验是单次任务**，图上已标注。

### 8.3 需要如实说明的边界

- 演示任务的目标集合结构高度同质，性格只能改变"支架密度与尾部顺序"，不可能让 6 个目标
  完全换成另一组；把它当成"个性化 = 补多少前置、从哪切入"来看待是准确的。
- 上述目标函数是在学位论文式(5-3)、修订版论文式(14) 的基础上做了两处展示性扩展：**归一化加权**与**长期价值项**，
  论文实验的数值没有使用这两项，群体结论仍以 Python 输出（`dynamic_outputs/*.json`）为准。

## 九、第三轮修订（2026-11，针对"目标像一门课、要看不同学科"）

### 9.1 问题

原平台只挂了一个任务（起点「信息交换」+ 6 个计算机网络目标），答辩时容易被理解成
"这套方法只对一门课有效"。图谱本身其实是跨学科的：410 个概念里既有计算机网络，
也有数据结构、数学、操作系统与数理逻辑。

### 9.2 做法

新增 `data/subjects.json`（由 `../3_dual_state/13_export_subject_tasks.py` 导出），预置五个学科任务包：

| 学科 | 起点 | 目标数 | 目标均难 |
|---|---|---|---|
| 计算机网络 | 信息交换 | 6 | 0.84 |
| 数据结构与算法 | 程序设计 | 6 | 0.75 |
| 数学与概率统计 | 数学 | 6 | 0.75 |
| 操作系统与计算机系统 | 操作系统 | 6 | 0.65 |
| 数理逻辑与离散数学 | 数理逻辑 | 6 | 0.72 |

- **可达性是真的**：每个目标都用 `nx.has_path` 从起点做有向校验，不可达的组合直接报错退出，
  不写进 JSON。之所以必须校验，是因为引擎的 `plan()` 遇到不可达目标不会报错，而是直接排入路径，
  会排出一条看似正常、实际跨学科的非法路径。
- **不新造概念、不改图**：五个包共 30 个概念全部取自全图原有的 410 个概念；平台执行的仍是
  同一个 `Replanner`，切换学科只换任务，不换模型与参数。
- **三处界面改动**：
  1. 「本轮学习目标」卡片顶部加学科选择按钮；
  2. 新增「同一名学生，换一门学科会走成什么样」卡片，并列显示五个学科各自需要多少步、
     插入多少支架节点、目标均难多少，点卡片即切换（悬停可看完整路径）；
  3. 双轨页标题栏显示当前学科；当某学科在默认画像下两轨结局相同时，图下会说明
     "本学科改变的是执行顺序而非完成率"，并给出可操作的对照方式，避免误以为回放失效。

### 9.3 顺手修掉的两个缺陷

1. `renderPersonas()` 定义了却从未调用，导致左侧「选择学生模板」一片空白。
2. 跨学科卡片在步数相同时显示"比当前多 0 步"，改为"与当前同样 N 步"。

### 9.4 边界

- 学科划分是按概念语义人工归类的，图本身不带宽严的课程标签；同一门课的边界在这里并不闭合
  （例如"数据结构"包的目标里会出现"平均查找长度"这类算法概念）。
- 五个包的目标数都是 6，所以默认画像下有四个包都是 7 步。步数相同不代表路径相同：
  内容、难度结构（0.65~0.84）与后续执行过程都不同。若要让步数也拉开，应选择先修距离更远的目标，
  而不是人为增删目标凑数。
